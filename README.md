# Goal
  Learn how to use Typescript, 3js and Voxel game engines (we could have used c++, OpenGL, godot, etc. but the idea was to try something new) and put in practice ECS pattern.

## Stack
 - Typescript
 - 3js


## Prerequisites

- [Bun](https://bun.sh/) (v1.0 or higher)

## Getting Started

### 1. Install dependencies
```bash
bun install
### 2. Run in local
```bash
bun run dev
